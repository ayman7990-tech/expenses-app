# مشروع المصاريف

تطبيق مصاريف شخصي باللغة العربية، يعمل محلياً في المتصفح بدون سيرفر أو إنترنت.
البيانات كلها محفوظة في `localStorage` على جهازك.

## المميزات

- تسجيل المصاريف حسب الصنف والتاريخ، مع تقارير وأرسوم بيانية.
- **نظام 90/10:** تدخل المرتب كامل؛ 10% ادخار محمي و90% سقف للمصاريف.
  التطبيق يمنع أي مصروف يلمس الادخار ويحذّرك قبل الوصول للسقف.
- **الادخار المتراكم:** 10% من كل شهر تتجمع، مع رسم نمو وعدّاد لتغطية المدخرات.
- نسخة احتياطية JSON (تصدير واسترجاع) + استيراد/تصدير CSV.
- واجهة متجاوبة: شريط تنقل سفلي على التلفون.

## الملفات

| الملف | الاستخدام |
|---|---|
| `index.html` | النسخة الكاملة (كمبيوتر) - افتحها مباشرة |
| `مشروع_المصاريف_للتلفون.html` | ملف واحد مستقل (CSS + JS مدمجان) للتلفون |
| `assets/css/style.css` | التصميم |
| `assets/js/app.js` | المنطق والتخزين |
| `build_single.py` | يعيد بناء نسخة التلفون بعد أي تعديل |

## التشغيل

افتح `index.html` أو `مشروع_المصاريف_للتلفون.html` في أي متصفح حديث.
لا يوجد بناء أو تثبيت مطلوب.

## إعادة بناء نسخة التلفون بعد تعديل الكود

```bash
python build_single.py
```

## الخصوصية

لا يوجد أي إرسال للبيانات لأي سيرفر. كل شيء يبقى على جهازك/متصفحك.
